# Código fuente

Directorio reservado para el código de la plataforma.

## Estado

Bootstrap. No contiene implementación. La Fase 0 definirá el inventario, la
evaluación de reutilización y el backlog antes de crear componentes.

## Reglas

- No incluir secretos, credenciales ni datos personales.
- Documentar la naturaleza de cada componente (PoC o práctica profesional).
- Añadir pruebas y criterios de aceptación junto con el código.
- Mantener cada cambio pequeño, verificable y reversible.
